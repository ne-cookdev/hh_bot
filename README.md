# hh vacancy bot

Телеграм-бот присылает новые вакансии с hh.ru. У каждого пользователя свои поиски. Уже отправленные вакансии лежат в SQLite и после перезапуска не приходят снова.

Публичный `GET https://api.hh.ru/vacancies` с апреля 2026 отвечает 403 без одобренного приложения работодателя. Бот читает ту же выдачу, что и сайт (`/search/vacancy`), одним запросом на уникальный фильтр, не чаще одного запроса в секунду. На 429 останавливает цикл и ждёт `Retry-After`.

## Запуск

Нужен Docker.

```powershell
copy .env.example .env
```

В `.env` положи токен от [@BotFather](https://t.me/BotFather):

```
BOT_TOKEN=123456:abcdef
```

```powershell
docker compose up -d --build
docker compose logs -f
```

База: `data/bot.sqlite3`. Если Windows держит `bot.sqlite3-wal`, бот переносит данные в `data/hh.sqlite3` и дальше пишет туда. Логи: `data/logs/bot.log` и `docker compose logs`.

Остановка: `docker compose down`. Файл базы при этом остаётся.

## Как пользоваться

Кнопки внизу, писать команды не нужно.

- **Поиски** — добавить, список, удалить один, очистить все.
- **Исключения** — слова, которые дописываются ко всем поискам как `AND NOT`.
- **Пауза** — копим новые, но не шлём, пока не включишь обратно.
- В карточке поиска **Все вакансии** — полный список с сайта, по 10, сначала новые.
- Автоотправка — не больше 15 за раз. Остаток приходит следующим заходом или по кнопке «Ещё». «Хватит» выкидывает хвост очереди.
- Одна и та же вакансия из нескольких поисков приходит один раз.

Новый поиск не вываливает весь архив. Берутся вакансии за последние несколько минут и всё, что выйдет потом. Старые — через «Все вакансии».

Опрос примерно каждые 40 секунд, плюс сразу после сохранения поиска. Пока запросов немного, сообщение обычно приходит быстрее чем за минуту.

### Два поиска вместо одного сложного

«Москва, любой формат» и «любой город, но только удалёнка» — два сохранённых поиска. Дубликат вакансии всё равно придёт один раз.

### Свой запрос

Язык как у строки поиска на hh.ru: `AND` `OR` `NOT`, скобки, кавычки, `NAME:` / `COMPANY_NAME:` / `DESCRIPTION:`, `!слово` без синонимов.

```
(NAME:frontend OR NAME:front-end OR NAME:фронтенд OR NAME:фронтэнд) AND React NOT стажер NOT intern NOT internship
```

Регион, формат (удалённо / офис / гибрид), опыт и зарплата от — кнопками, в текст их писать не надо.

Простой конструктор сам собирает такой запрос: слова в названии через `OR` внутри `NAME:`, дополнительные слова через `AND`.
